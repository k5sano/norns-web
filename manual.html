norns-web マニュアル

monome norns の Lua スクリプトをブラウザで動かすエミュレータです。norns.community のスクリプトを入れて遊んだり、自分でスクリプトを書いて試したりできます。

01はじめに

  1. ページを開くと、サンプルの step（8ステップのシーケンサー）が自動で動き出します。
  2. 画面のどこかを一度クリックすると音が出ます。ブラウザの決まりで、操作するまでは無音です。右上のボタンが「音 ON」（緑）なら出力中です。
  3. 右の「ライブラリ」タブから、norns.community のスクリプトを選んで「インストール」を押すと、取り込んですぐ起動します。

パソコンの Chrome / Edge / Safari / Firefox で動きます。スマホでも動きますが、エンコーダーやグリッドの操作はパソコンの方が快適です。実機グリッドの接続はパソコン版の Chrome と Edge だけです。

02画面の見方

本体（左上）128×64 の画面、キー K1〜K3、エンコーダー E1〜E3、MENU ボタン。
コントローラ（左下）GRID 128 / ARC 4 / CROW のタブ。スクリプトが使うものには黄色い点が付き、最初に使われたタブに自動で切り替わります。
エディタ（右）スクリプトの表示と編集、実行・停止、MATRON（ログ）と REPL。
ライブラリ（右）カタログ検索、インストール、取り込み済みの一覧、音声ファイル。

右上の表示は実行状態です。緑は実行中、赤はエラーが出たことを表します。エラーの内容は MATRON 欄に出ます。

03本体の操作

マウス・タッチ

  • キー：押している間が「押下」、離すと「離した」としてスクリプトに届きます。
  • エンコーダー：つまみの上で上下（または左右）にドラッグして回します。マウスホイールでも回せます。クリックして選んだ状態なら矢印キーでも回せます。
  • MENU：K1 の短押しと同じで、システムメニューを開閉します。

キーボード

キー動作
1 2 3K1 / K2 / K3
Q WE1 を左 / 右に回す
A SE2 を左 / 右に回す
Z XE3 を左 / 右に回す
Ctrl/⌘ + Enterエディタで編集中のスクリプトを実行

エディタや入力欄に文字を打っている間は、上のキーは本体操作になりません。

04システムメニュー

K1 を短く押す（または MENU）と開き、もう一度押すとスクリプトの画面に戻ります。K1 を押したまま他のキーやエンコーダーを使うと、メニューは開かずスクリプトに K1 として届きます。E1 でページを切り替えます。

ページ操作
MIXE2 で項目（out / eng / cut / rev）を選び、E3 で音量を変えます。
TAPEこの版では未対応です。
HOMEE2 で項目を選び K3 で決定。SELECT で dust/code 内のスクリプトを選んで起動、SYSTEM で再起動、SLEEP で画面を消します。K2 で戻ります。
PARAMETERSE2 で選び、E3 で値を変えます。トリガー・オンオフ・ファイル・文字列の項目は K3 で操作します。

05スクリプトを入れる

カタログから

「ライブラリ」タブの下半分が norns.community のカタログです。名前・作者・タグで検索し、絞り込み（起動確認済み / softcut / grid / arc / crow など）もできます。

  • インストール：GitHub から直接ブラウザに取り込み、すぐ起動します。git submodule も一緒に取り込みます。ほかのプロジェクトを必要とするスクリプトは、それも続けて入れます。
  • 起動確認済：こちらで起動してエラーが出なかったスクリプトです。付いていないものも動くことがあります。
  • チップの見方：緑のエンジン名は対応済み、黄色の「代替音」は簡易シンセで鳴らします。「要: ○○」は必要な別プロジェクト、「midi（未対応）」は MIDI 機能が使えないことを表します。
回数の上限　GitHub の仕組みで、インストールは1時間に約60回（1プロジェクト＝1回＋submodule ごとに1回）までです。上限に達すると、何時から再開できるかが表示されます。

インストール済みの管理

「インストール済み · dust/code」の一覧から、実行・更新・削除ができます。更新は GitHub から最新版を取り直すので、自分で編集した内容は消えます。削除は2回押すと実行されます。

ファイルから

カタログにないスクリプトは、上部の枠に ZIP か .lua をドロップします（クリックしてファイルを選ぶこともできます）。ZIP は dust/code/<名前>/ に展開され、起動できるファイルが自動で開きます。音声ファイル（wav / aif / flac / mp3 / ogg など）は dust/audio/、png は dust/data/images/ に入ります。

06エディタと REPL

  • 上のプルダウンで dust/code 内のファイルを選びます。編集内容は自動で保存されます。
  • ▶ 実行（Ctrl/⌘+Enter）で今のファイルを起動、■ 停止で止めます。Tab は空白2つを入れます。
  • ＋ 新規で untitledN というスクリプトを作ります。
  • 元に戻すは同梱サンプルを最初の状態に戻します。

MATRON 欄には print の出力とエラーが出ます。一番下の >> 欄は REPL で、実行中のスクリプトの中で Lua を1行ずつ試せます。

例結果
engine.hz(440)440Hz を1音鳴らす
params:get('clock_tempo')今のテンポを表示
params:set('clock_tempo', 140)テンポを変える
tab.print(params.lookup)パラメータ ID の一覧

07grid · arc · crow

GRID 128

16×8 のパッドをクリック・タップすると、スクリプトの g.key(x, y, z) に届きます。複数の指で同時に押せます。実機をつなぐ方法は次の章にあります。

ARC 4

リングの外側をなぞるように回すと a.delta(n, d)、中央のつまみを押すと a.key(n, z) に届きます。ホイールでも回せます。

CROW

  • OUT 1〜4：出力電圧（−5〜+10V）をバーで表示します。
  • IN 1 / IN 2：スライダーで入力電圧を作ります。「5V」ボタンは押している間 5V になるゲートです。
  • 音で聴く：OUT 1 を音程（V/oct）、OUT 2 を音量（VCA）として鳴らします。

crow.ii（i2c 機器）と crow 本体で動くスクリプト（crow.loadscript など）は無視されます。

08実機グリッド

本物の monome grid を USB でつなぎ、エミュレータの grid として使えます。パソコン版の Chrome / Edge が必要です。

  1. serialosc など、ほかのソフトがグリッドを使っていれば止めます。
  2. GRID 128 タブの「USB grid に接続」を押し、一覧からグリッドを選びます。
  3. 「接続中」と表示されたら、キーとLEDがスクリプトとつながります。

機種と通信方式

設定対象
自動判別mext が応答すれば mext、しなければ series として扱います。
mext2011年以降の grid。サイズも自動で判別します。
series2007〜2010年の monome 64 / 128 / 256。サイズは手で選びます。
40h2006年の 40h と arduinome（通信速度 57600 を選ぶ）。

256 では上半分の 16×8 を使います。ケーブルの向きが逆になる置き方なら「向き」を 180°にします。

階調としきい値

スクリプトは LED の明るさを 0〜15 の16段階で指定します。実機の性能に合わせて、どのレベルからどの明るさで光らせるかを決められます。

  • 16段階：varibright 機向け。そのまま送ります。
  • 4段階：段階1〜3（暗・中・明）が、それぞれレベルいくつ以上で光るかを決めます。各段階で実機に送る値（初期値 5 / 10 / 15）も変えられます。
  • 点灯 / 消灯のみ：単色の初代機向け。レベルいくつ以上で点灯させるかを1つ決めます。
0123 4567 891011 12131415

4段階の初期設定：0〜3 は消灯、4〜7 が暗、8〜11 が中、12〜15 が明。

設定欄の「対応表」に、今の設定で各レベルがどうなるかが出ます。「押している間テスト表示」を押すと、実機の左の列から順にレベル 0〜15 が並ぶので、どの列から光るかを見ながら合わせます。「画面のグリッドも同じ階調で表示」をオンにすると、画面上の grid も実機と同じ見え方になります。

一覧に出ないとき　初代機（FTDI チップ）は、パソコン側に FTDI のドライバが必要なことがあります。macOS は標準で入っています。

09音と softcut

エンジン

エンジン状態
PolyPerc対応（hz amp cutoff release pw gain pan）
TestSine対応
PolySub / MollyThePoly簡易版。音色は近いものになります。
その他SuperCollider 製のエンジンは未実装です。音程を指定するコマンドは代わりのパーカッシブ音で鳴らします。

softcut

6ボイス・2バッファ（各約87秒）で、再生速度・ループ・クロスフェード・録音とオーバーダブ・フィルター・ボイス間の送り・位置の通知・波形表示・音声ファイルの読み書きに対応しています。

AUDIO IN

本体の下にある「AUDIO IN」で、録音元を選べます。「テストトーン」は簡単なアルペジオ、ほかに dust/audio に入れた音声ファイルをループで流せます。マイク入力には対応していません。

ほかに、reverb と compressor（オン / オフと量）、amp_in / amp_out の poll が使えます。

10対応範囲

カタログの約4分の3のスクリプトがエラーなく起動します。動かないものの主な理由は次のとおりです。

  • SuperCollider 製エンジンが追加するパラメータを前提にしている
  • MIDI 機器が必須
  • ネット接続や OS のコマンドを使う
  • 音声やプリセットのファイルが dust に入っている前提

使える主なライブラリ

util tabutil controlspec musicutil sequins lattice lfo reflection pattern_time er formatters ui graph filtergraph envgraph voice fileselect textentry listselect cjson など。include と require は dust/code 内のファイルとこれらのライブラリを読みます。

未対応

MIDI、crow.ii、tape、マイク入力、OSC、mod の読み込みは使えません。呼び出してもエラーにはならず、無視されます。

11データの保存

入れたスクリプト、編集内容、音声ファイル、pset などは、すべて使っているブラウザの中（IndexedDB）に保存されます。サーバーには何も送りません。

  • 別のブラウザや端末では、最初の状態から始まります。
  • 同じ URL を友達に送っても、あなたのデータは見えません。
  • 全部消して初期状態に戻すには、ブラウザの設定でこのサイトのデータを削除します。

12困ったとき

症状確認すること
音が出ない右上のボタンが「音 ON」（緑）になっているか。「音 OFF」ならクリックします。iPhone / iPad は本体の消音スイッチがオンだと鳴らないことがあります。ほかに、パソコンの出力先、MIX ページの音量も確認します。PolyPerc 以外のエンジンを使うスクリプトは、代替音か無音のことがあります。
右上が赤くなったMATRON 欄のエラーを見ます。include: … が見つかりません は必要なファイルや別プロジェクトがない状態です。
インストールが失敗する回数の上限（1時間約60回）か、ネットワークの問題です。表示された時刻以降にもう一度押します。
動きが止まった■ 停止 → ▶ 実行 で起動し直します。無限ループは自動で中断され、MATRON に timeout と出ます。
実機グリッドがつながらないChrome / Edge か。serialosc を止めたか。古い機種はプロトコルとサイズを手で選んでみます。
