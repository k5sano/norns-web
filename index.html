          対応している norns API
          

            
screen
clear update level move line rect circle arc curve stroke fill pixel text text_right text_center text_rotate text_extents font_size font_face line_width blend_mode display_png peek …

            
softcut
6ボイス・2バッファ（各約87秒）。rate / loop / fade / rec・pre / post filter / level_cut_cut / phase poll / render_buffer / buffer_read・write

            
crow
output.volts / slew / action（to, loop, times, held, dyn, lfo, ar, adsr, pulse …）· input.mode stream / change

            
clock · metro
clock.run / sleep / sync / cancel · metro.init · poll（amp_in / amp_out）

            
params
number option control taper binary trigger text file separator group · pset の読み書き

            
lib
util tabutil controlspec musicutil sequins lattice er formatters ui pattern_time beatclock fileselect textentry listselect intonation

            
engine
PolyPerc · TestSine · PolySub（簡易）· MollyThePoly（簡易）。ほかのエンジンは音名系コマンドを代替音で鳴らします

            
grid · arc
g:led all refresh · g.key · a:led all segment refresh · a.delta a.key
